## ROLLBACK PLAN

  If the consolidated backend fails:

  1. Old services were deleted — cannot rollback to them
  2. Git tag `pre-consolidation` exists for code reference
  3. If critical: redeploy from pre-consolidation tag
     git checkout pre-consolidation
     (requires recreating old service dirs)

  Best approach: fix forward. The consolidated backend is the single source of truth.


## TROUBLESHOOTING

  Port scan timeout:
    Free tier sleeps after 15 min inactivity.
    First request takes 30-60 seconds to wake up.
    Set NODE_ENV=production for faster cold starts.

  Module not found:
    Build command might be wrong.
    Check that prisma generate runs during build.

  Database connection failed:
    Verify DATABASE_URL is correct.
    Check PostgreSQL is running in Render dashboard.
    Use Internal URL for Render services, External for local.

  WebSocket not connecting:
    Free tier doesn't support WebSocket upgrades.
    Consider using Socket.io with polling fallback.

  500 on /api/v1/health:
    Check Render logs for build errors.
    Verify prisma generate completed.
    Check DATABASE_URL is reachable.

  CORS errors:
    Verify CORS_ORIGIN matches your frontend URLs exactly.
    No trailing spaces, comma-separated.
