                    DINANWUYE BACKEND CONSOLIDATION PLAN
                    ====================================
                    Last Updated: 2026-08-30
================================================================================

OBJECTIVE
---------
Consolidate all separate Node.js microservices into a single NestJS application
to eliminate cold starts, simplify deployment, and reduce complexity on Render.

Current Architecture: 6+ separate Render services
Target Architecture:  1 consolidated NestJS app + 1 Python matching service

2. Frontend apps (main app, admin app) remain as separate Render services
3. Only BACKEND Node.js services are being consolidated
