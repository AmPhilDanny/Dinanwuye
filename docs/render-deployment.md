# Render Deployment Guide — Consolidated Backend

## Quick Start (Render Blueprint)

1. Go to https://dashboard.render.com
2. Click **New +** → **Blueprint**
3. Connect GitHub repo: `AmPhilDanny/Dinanwuye`
4. Select branch: `feat/consolidate-backend`
5. Render auto-detects `render.yaml` and creates:
   - `dinanwuye-api` (web service)
   - `dinanwuye-db` (PostgreSQL)
   - `dinanwuye-redis` (Redis)
6. Wait for first deploy to complete (~5-10 min)

## Post-Deploy: Set Environment Variables

Go to `dinanwuye-api` → **Environment** tab and set:

| Key | Value | Notes |
|-----|-------|-------|
| `SUPABASE_URL` | https://your-project.supabase.co | From existing Supabase |
| `SUPABASE_SERVICE_KEY` | `eyJ...` | Service role key |
| `SUPABASE_ANON_KEY` | `eyJ...` | Anonymous key |
| `SMTP_HOST` | smtp.example.com | From email provider |
| `SMTP_PORT` | 587 | |
| `SMTP_USER` | your@email.com | |
| `SMTP_PASS` | xxx | |
| `VAPID_PUBLIC_KEY` | `BP...` | Web push public key |
| `VAPID_PRIVATE_KEY` | `xxx` | Web push private key |
| `VAPID_SUBJECT` | mailto:admin@dinanwuye.com | |
| `STRIPE_SECRET_KEY` | `sk_live_xxx` | Or `sk_test_xxx` for testing |
| `STRIPE_WEBHOOK_SECRET` | `whsec_xxx` | |
| `PAYSTACK_SECRET_KEY` | `sk_xxx` | |
| `PAYSTACK_WEBHOOK_SECRET` | `xxx` | |

**Auto-generated (don't overwrite):**
- `JWT_SECRET` — generated by Render
- `JWT_REFRESH_SECRET` — generated by Render
- `DATABASE_URL` — from linked PostgreSQL
- `REDIS_URL` — from linked Redis

## Verify Deployment

```bash
# Health check
curl https://dinanwuye-api.onrender.com/api/v1/health

# Swagger docs
open https://dinanwuye-api.onrender.com/docs
```

## Run Database Migrations

If `prisma migrate deploy` didn't run during build:

1. Go to `dinanwuye-api` → **Shell**
2. Run:
   ```bash
   cd backend/consolidated-app
   npx prisma migrate deploy
   npx prisma generate
   ```

## Update Frontend API URL

Update `frontend/src/services/api.js`:
```javascript
// OLD: Multiple service URLs
// NEW: Single consolidated API
const API_BASE = 'https://dinanwuye-api.onrender.com/api/v1';
```

## Rollback Plan

If issues arise:
1. Keep old services running until consolidated backend is verified
2. Point frontend back to old service URLs
3. Revert to `pre-consolidation` tag: `git checkout pre-consolidation`
